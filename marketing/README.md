# Marketing content

This directory is **website source content** for Vibe Practice Management. Every file is publish-ready Markdown you can lift into a CMS, static-site generator, or page builder with little or no editing. It describes only capabilities that ship in the product today.

## How to use it

- **Headlines** (the H1 in each file) are written as web heroes / section titles.
- **Ledes** are the supporting sentence under a heading.
- **Feature bullets** follow a `**Capability** — benefit.` pattern so they drop cleanly into feature grids or bulleted lists.
- Pull whole files for feature pages, or mix bullets across files to build a landing page.

## Files

- `overview.md` — product overview, who it's for, and the headline value propositions. Start here for the homepage.
- `feature-index.md` — a flat, grouped list of every feature. Use it as navigation, a sitemap, or a "full feature list" page.
- `features/` — one page per feature area (15 files). Each is a self-contained feature page.

## Voice & tone

- **Audience:** firm owners, partners, and practice administrators at CPA firms (roughly 5–50 timekeepers).
- **Register:** professional, plain-English, confident. Lead with the benefit to the firm, not the architecture.
- **Avoid:** internal build lingo (phase numbers, table names), and competitor names or comparisons.
- **Product name:** *Vibe Practice Management* (short form: *Vibe PM*).
